# Compression Metrics — Draft

No metric is committed yet. Candidate measures are hypotheses to be evaluated against the corpus and against competing models.

## 1. Inferential distance

Number or weighted cost of inferential steps between empirical premises and normative conclusions.

## 2. Premise displacement

Proportion of premises required to reconstruct the normative conclusion that are not explicitly stated in the local argument but are recoverable from a classification or definition.

## 3. Graph compression

Compare expanded and observed argument graphs using node/edge counts, path length, and description length.

## 4. Information-theoretic compression

Explore whether a minimum-description-length or related measure can represent the amount of inferential structure carried by a classificatory node.

## 5. Boundary-preservation effect

Estimate whether boundary-policing events are more likely when category expansion would weaken the associated normative inference.

## Important constraint

The project must not define a metric so that the desired result follows by construction. Candidate metrics should be evaluated on simulated data containing known positive, null, and adversarial cases before corpus application.
