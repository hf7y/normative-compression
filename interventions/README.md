# Intervention Program

The eventual intervention program asks whether conceptual engineering can be practiced experimentally rather than only observed retrospectively.

## Candidate design

Construct alternative conceptual formulations of the same underlying empirical situation while controlling as much non-conceptual information as possible.

Measure effects on:

- classification;
- inferential recall;
- information loss;
- ambiguity;
- normative judgment;
- uptake;
- robustness to counterexamples;
- stability across audiences.

## Sequencing constraint

Intervention work should follow, rather than precede, validation of the descriptive ontology and formal measurement model. Otherwise the intervention risks merely demonstrating the assumptions built into its own design.

## Philosophical significance

If controlled conceptual transformations reliably alter downstream inferences, that would provide empirical evidence for the practical claim that conceptual vocabularies shape normative reasoning. It would not by itself establish which vocabulary is morally preferable.
