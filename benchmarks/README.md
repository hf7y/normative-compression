# Benchmark Suite

The benchmark suite is intended to provide independently specified ground truth for validating conceptual-compression metrics.

## Required categories

- explicit normative argument;
- ordinary descriptive classification;
- descriptive compression;
- normative compression;
- definitional compression;
- boundary policing;
- counterexample-driven reclassification;
- conceptual engineering;
- superficially similar non-engineering cases.

## Design principle

Annotators should label observable argumentative components rather than the target phenomenon itself. The benchmark should therefore permit the model to calculate compression from premises, classifications, conclusions, and inferential relations rather than asking annotators whether a passage is "normatively compressed."

## Gold-standard development

Ground truth should be established independently of the eventual quantitative metric through expert annotation, explicit adjudication rules, and agreement statistics.
