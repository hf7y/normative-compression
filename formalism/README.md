# Formalism

This layer tests whether mathematical frameworks from signal processing, information theory, and graph theory can model conceptual operations.

## Primary candidates

- argument graphs;
- graph distance and path length;
- compression and description length;
- information loss;
- distortion;
- encoding and decoding;
- filtering and error correction;
- mutual information and related measures where probability models can be justified.

## Methodological warning

A signal-processing analogy is not a measurement. A quantity becomes a legitimate metric only when its variables, probability distributions, units or scale, assumptions, and interpretation are specified and independently validated.

The project therefore treats the formalism as a hypothesis to test.

## Independent hypothesis

H2: signal-processing, information-theoretic, or graph-theoretic concepts provide a useful formal representation of normative compression.

H2 can fail even if normative compression itself is empirically supported.

## Minimum validation requirement

Before applying a metric to a large natural-language corpus, test it on synthetic arguments whose compression structure is known in advance. The metric should recover the known ordering and distinguish compression from superficially similar phenomena.
