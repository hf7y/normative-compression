# Corpus Design

## Principle

The corpus must be designed to make cherry-picking difficult. Sampling rules should be established before inspecting results where practical.

## Proposed strata

### Target

Academic discourse containing Indigenous and related territorial/political classifications.

### Historical/descriptive controls

Comparable terms such as native, aboriginal, autochthonous, settler, colonist, immigrant, ethnic, and national, subject to final corpus-design review.

### Normative conceptual controls

Terms such as citizen, refugee, minority, victim, sovereign, and related classifications may be used to test whether compression is general across normative categories.

### Neutral/descriptive controls

Terms with substantially weaker expected normative loading can test whether ordinary classification produces the same graph structure.

These lists are hypotheses about useful strata, not final inclusion criteria.

## Unit of analysis

The project should distinguish:

- document;
- passage;
- claim;
- argument;
- classification event;
- boundary-policing event.

A document may contain many units of analysis.

## Metadata

At minimum:

- author;
- publication year;
- discipline;
- genre;
- venue;
- geography/topic where available;
- document type;
- source URL/identifier;
- sampling stratum;
- advocacy/position coding if independently defensible.

## Sampling

Prefer stratified random sampling within defined source populations. Record all exclusions. Preserve a held-out test set for confirmatory analysis where feasible.
