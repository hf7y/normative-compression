# Preregistration

This file is intentionally a placeholder until pilot work is complete.

The confirmatory specification should freeze:

- corpus sampling frame;
- inclusion/exclusion rules;
- primary and secondary outcomes;
- compression metric;
- annotation rules;
- reliability thresholds;
- statistical model;
- control variables;
- exclusion rules;
- robustness analyses;
- visualization plan;
- criteria for supporting, weakening, or falsifying H1.

Pilot exploration must not silently become confirmatory evidence.
